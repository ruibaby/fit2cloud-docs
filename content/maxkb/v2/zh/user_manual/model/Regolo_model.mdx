## 1 添加模型


添加 Regolo 大模型之前，需要先在 [Regolo AI](https://regolo.ai/) 创建 API Key。

选择模型供应商为`Regolo`，并在模型添加对话框中输入如下必要信息：

* 模型名称：MaxKB 中自定义的模型名称。     
* 模型类型：大语言模型/向量模型/图片生成。   
* 基础模型：不同类型模型下的基础模型名称，下拉选项是常用的一些基础模型名称，支持自定义输入。
* API Key：获取 API Key。
