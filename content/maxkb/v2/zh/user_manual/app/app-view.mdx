title: 智能体概览

创建完智能体，进入在概览页面可以进行启用/禁用/重新生成公开访问链接、演示、嵌入第三方、访问限制以及 API Key 管理。

## 1 公开访问链接


公开访问链接支持开关设置和重新生成。点击演示或复制公开访问链接至浏览器进入问答页面。

<img style={{display:"block",margin:"16px auto",maxWidth:"100%"}} src={"/maxkb/img/maxkb/app/QA.png"} alt="图 2  问答对话界面" />

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 2  问答对话界面</div>

<img style={{display:"block",margin:"16px auto",maxWidth:"100%"}} src={"/maxkb/img/maxkb/app/QA_asker.png"} alt="图 3  问答提问界面" />

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 3  问答提问界面</div>


在问答后，可以点击右上角的导出按钮，可以选择将当前的对话记录导出为 Markdown、HTML 和 PDF 文件。

<img style={{display:"block",margin:"16px auto",maxWidth:"100%"}} src={"/maxkb/img/maxkb/app/QA_down.png"} alt="图 4  问答导出对话" />

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 4  问答导出对话</div>


当选择导出为 PDF 时，支持选择导出为 PDF 或图片。

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 5  导出 PDF 或图片</div>


支持复制、换个答案、赞同、反对和分享聊天记录。

<img style={{display:"block",margin:"16px auto",maxWidth:"100%"}} src={"/maxkb/img/maxkb/app/QA_share.png"} alt="图 6  问答分享" />

## 2 嵌入第三方


MaxKB 智能体支持零编码嵌入到企业的第三方系统。     
在智能体概览页面点击【嵌入第三方】，复制全屏模式、移动端模式或浮窗模式代码嵌入到第三方系统中，即可在第三方系统中进行问答。

<img style={{display:"block",margin:"16px auto",maxWidth:"100%"}} src={"/maxkb/img/maxkb/app/embed.png"} alt="图 8  嵌入第三方" />

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 8  嵌入第三方</div>

## 3 访问限制


MaxKB 支持对智能体设置每个客户端提问次数限制和嵌入第三方白名单防盗链设置。

**注意**：身份验证为 X-Pack 功能。

<img style={{display:"block",margin:"16px auto",maxWidth:"100%"}} src={"/maxkb/img/maxkb/app/Accessrestrictions.png"} alt="图 9  客户端访问限制" />

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 9  客户端访问限制</div>

社区版本智能体支持语言以及显示执行详情的设置。X-Pack 功能更多设置，详情见：[智能体显示](../X-Pack/app_logo_settting)

## 5 API 访问凭据


如果外部系统需要通过 API 的方式进行调用，需要查看 API 文档和当前智能体的 API Key，点击 【API Key 】，打开 API Key 的管理对话框，支持创建、启用/禁用、删除 API Key。
