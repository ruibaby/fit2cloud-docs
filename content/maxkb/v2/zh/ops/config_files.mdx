## 1 功能简介

MaxKB 的运行参数主要保存在运行目录的 `.env`。调整服务端口、数据库、Redis、工作流循环上限等，一般改这个文件后重新加载即可。

## 2 配置文件位置

## 3 修改与生效

修改前先备份：

```sh
cp /opt/maxkb/.env /opt/maxkb/.env.bak.$(date +%F)
vi /opt/maxkb/.env
```

保存后重新加载：

```sh
mkctl reload
```

:::warning[修改后需重新加载]
配置不会热更新，须执行 `mkctl reload`（或等价的容器重建 / 重启）。见 [命令行工具](../installation/cli.mdx)。

:::

:::note[其他可调项]
- 暴露内置 PostgreSQL 端口：在 `/opt/maxkb/.env` 中调整端口映射后执行 `mkctl reload`，见 [安装部署 FAQ](../faq/install_configuration.mdx)。
- 工作流无限循环上限：默认最大循环 1000 次，可在 `.env` 中修改后执行 `mkctl reload`，见 [工作流应用](../user_manual/app/workflow_app.mdx)。

:::
