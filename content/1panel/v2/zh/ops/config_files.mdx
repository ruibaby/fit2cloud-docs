## 1 功能简介

1Panel 的安装目录、端口、初始用户等基础信息保存在 `1pctl` 中；安全入口、授权 IP、外观等面板参数多在控制台维护。日常改端口、账号等，优先用 `1pctl`，不要手改脚本。

## 3 修改与生效

修改前建议备份 `1pctl`：

```sh
cp /usr/local/bin/1pctl /usr/local/bin/1pctl.bak.$(date +%F)
```

再按需调整：

```sh
1pctl user-info
1pctl update port
1pctl update username
1pctl update password
1pctl listen-ip ipv4
```

修改后重启：

```sh
1pctl restart
```

:::warning[修改后需重启]
通过 `1pctl` 调整基础参数后，一般需执行 `1pctl restart`。见 [1pctl 命令行工具](../installation/cli.mdx)。

:::
