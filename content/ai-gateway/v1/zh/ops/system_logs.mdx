## 1 功能简介

1Panel AI 网关以容器方式部署。排查启动失败、初始管理员密码、接口报错或进程异常时，主要依赖容器标准输出日志。本文介绍默认容器名、数据目录，以及使用 Docker 查看运行日志的方法。

## 2 前提条件

- 已使用具备服务器权限的账号登录网关所在主机。
- 已确认容器名与数据目录。官方示例默认容器名为 `1panel-ai-gateway`，数据目录挂载为 `/opt/ai-gateway:/opt/ai-gateway`；如已自定义，请按实际名称与路径替换本文示例。
- 主机已安装 Docker，且当前账号可执行 `docker` 命令。

- **运行日志**： 官方安装与排障文档通过 `docker logs` 查看容器输出（例如首次启动时检索 `initial administrator created` 获取临时管理员密码）。
- **数据目录**： `/opt/ai-gateway` 用于持久化数据库与安全相关文件（如 SQLite 库、凭据密钥等），升级或重建容器时应保留该目录。

## 4 查看容器日志

1. 查看最近的日志：

```sh
docker logs --tail 100 1panel-ai-gateway
```

2. 实时跟踪容器日志，按 `Ctrl + C` 结束：

```sh
docker logs -f 1panel-ai-gateway
```

3. 按时间范围查看，例如查看最近 30 分钟的日志：

```sh
docker logs --since 30m 1panel-ai-gateway
```

4. 首次启动后查找初始管理员临时密码：

```sh
docker logs 1panel-ai-gateway 2>&1 | grep "initial administrator created"
```

:::note[容器日志的留存范围]
`docker logs` 输出的内容随容器生命周期存在，容器重建（如升级、重新部署）后历史输出不再保留。需要长期留存时，可将 `docker logs` 结果重定向保存到其他目录。

:::
