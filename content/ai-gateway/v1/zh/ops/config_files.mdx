## 1 功能简介

AI 网关的业务配置（上游账号、模型组、密钥等）在管理界面维护；部署参数（端口、初始密码、代理等）通过 `docker run` 的环境变量与数据目录指定。

## 3 修改与生效

修改前先备份数据目录：

```sh
cp -a /opt/ai-gateway /opt/ai-gateway.bak.$(date +%F)
```

变更端口或环境变量时，先停删旧容器（**不要删除** `/opt/ai-gateway`），再按新参数重建并继续挂载原目录：

```sh
docker stop 1panel-ai-gateway
docker rm 1panel-ai-gateway
docker run --pull always -d \
  --name 1panel-ai-gateway \
  --restart unless-stopped \
  -p 8080:8080 \
  -v /opt/ai-gateway:/opt/ai-gateway \
  1panel/ai-gateway
```

:::warning[保留数据目录]
重建容器时必须继续挂载 `/opt/ai-gateway`。删除该目录或丢失 `credential.key` 会导致数据或凭据不可用。

:::
