## 1 功能简介

DataEase 的运行参数主要保存在安装目录的 `conf/application.yml`。调整跨域白名单、登录超时、导出限制等，一般改这个文件后重启即可。

## 3 修改与生效

修改前先备份：

```sh
cp /opt/dataease3.0/conf/application.yml /opt/dataease3.0/conf/application.yml.bak.$(date +%F)
vi /opt/dataease3.0/conf/application.yml
```

保存后重启：

```sh
dectl restart
```

:::warning[修改后需重启]
配置不会热更新，须执行 `dectl restart`。见 [命令行工具](./cli.mdx)。

:::
