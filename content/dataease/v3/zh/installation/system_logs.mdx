## 1 功能简介

DataEase 以容器方式部署，主服务及可选组件会把运行日志写入宿主机安装目录下的 `logs` 目录。当服务启动失败、同步任务异常或接口报错时，可通过查看系统日志定位原因。本文介绍系统日志的存放位置，以及通过日志文件与 Docker 容器两种方式查看日志的方法。

## 2 前提条件

- 已使用具备服务器权限的账号登录 DataEase 所在主机。
- 已确认 DataEase 的安装目录。默认 `DE_BASE=/opt`，运行目录为 `/opt/dataease3.0`；如已自定义，请按实际路径替换本文示例。
- 使用 Docker 方式查看日志时，主机已安装 Docker，且当前账号可执行 `docker` 命令。

- **DataEase**： 主日志位于 `logs/dataease/` 下，常见文件为 `info.log`、`error.log`，并按日期滚动生成历史文件。
- **同步任务**： 与主服务共用 `logs` 挂载；任务处理日志位于 `logs/dataease/sync-task/task-handler-log/`。
- **APISIX**： 企业版等场景下可选启用；日志写入 `apisix/logs`。社区版默认安装不一定包含该组件。

:::note[清理历史日志]
可使用 `dectl clear-logs` 清理 DataEase 历史日志。详见 [命令行工具](./cli.mdx)。

:::


## 4 查看日志文件

1. 查看日志目录下的文件列表：

```sh
ls -lh /opt/dataease3.0/logs/dataease
```

2. 实时跟踪主服务日志，排查进行中的问题时使用，按 `Ctrl + C` 结束：

```sh
tail -f /opt/dataease3.0/logs/dataease/info.log
```

:::warning[及时留存日志]
历史日志可能被清理或轮转。排查重要问题时，请先将相关日志复制到其他目录留存。

:::


## 5 查看容器日志

各组件的日志会同时输出到容器标准输出，可直接使用 Docker 命令查看。

1. 查看指定容器最近的日志，以 DataEase 主服务为例：

```sh
docker logs --tail 100 dataease
```

2. 实时跟踪容器日志，按 `Ctrl + C` 结束：

```sh
docker logs -f dataease
```

3. 按时间范围查看，例如查看最近 30 分钟的日志：

```sh
docker logs --since 30m dataease
```

:::note[容器日志的留存范围]
`docker logs` 输出的内容随容器生命周期存在，容器重建（如升级、重新部署）后历史输出不再保留。需要长期留存，请导出宿主机日志目录下的日志文件。

:::
