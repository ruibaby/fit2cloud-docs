title: "报告"
---

## 1 生成报告

:::note

在【测试计划】页点击【执行】生成测试计划报告。


:::


![!报告](</img/metersphere/test_plan/report/测试点生成报告.png>)

## 2 查看报告
### 2.1 计划报告

:::note

在【计划报告】页面，点击【报告ID】查看报告详情，输入【报告总结】进行保存。


:::


![!报告](</img/metersphere/test_plan/report/查看报告1.png>)

![!报告](</img/metersphere/test_plan/report/查看报告2.png>)

:::note[报告筛选]

在报告页面，拖拽到用例明细处，可开启测试点功能，页面按“测试点”维度展示列表数据。


:::


![!报告](</img/metersphere/test_plan/report/根据功能点展示报告.png>)

![!报告](</img/metersphere/test_plan/report/根据功能点展示报告2.png>)

### 2.2 计划组报告

:::note

在【计划组报告】页面，点击【报告ID】查看报告详情，输入【报告总结】进行保存。


:::


![!报告](</img/metersphere/test_plan/report/计划组报告.png>)

![!报告](</img/metersphere/test_plan/report/计划组报告结果.png>)

## 3 分享报告

:::note

点击【分享】获取报告分享链接。


:::


![!报告](</img/metersphere/test_plan/report/分享报告.png>)

## 4 导出报告

:::note

点击【导出 PDF】可下载 pdf 格式的报告。


:::


![!报告](</img/metersphere/test_plan/report/导出pdf报告.png>)
