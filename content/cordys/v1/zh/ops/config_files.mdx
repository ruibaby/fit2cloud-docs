## 1 功能简介

Cordys CRM 的运行参数保存在数据目录的 `conf/cordys-crm.properties`。调整数据源、Redis、会话超时、IP 白名单等，一般改这个文件后重启即可。

## 3 修改与生效

修改前先备份：

```sh
cp /opt/cordys/conf/cordys-crm.properties /opt/cordys/conf/cordys-crm.properties.bak.$(date +%F)
vi /opt/cordys/conf/cordys-crm.properties
```

需要启用的项去掉行首 `#` 并改值，保存后重启：

```sh
docker restart cordys-crm
# 离线安装也可：
csctl reload
```

:::warning[修改后需重启]
配置不会热更新，须重启容器或执行 `csctl reload` / `csctl restart`。见 [命令行工具](../installation/cli.mdx)。

:::
