## 1 功能简介

Cordys CRM 以容器方式部署，应用运行日志写入数据目录下的日志文件夹。当服务启动失败、接口报错或业务操作异常时，可通过查看系统日志定位原因。本文介绍系统日志的存放位置，以及通过日志文件与 Docker 容器两种方式查看日志的方法。

## 2 前提条件

- 已使用具备服务器权限的账号登录 Cordys CRM 所在主机。
- 已确认数据目录挂载。官方示例常见为 `-v ~/cordys:/opt/cordys` 或使用 `/opt/cordys`；如已自定义，请按实际路径替换本文示例。
- 使用 Docker 方式查看日志时，主机已安装 Docker，且当前账号可执行 `docker` 命令。

- **Cordys CRM**： 按级别写入 `trace.log`、`debug.log`、`info.log`、`warn.log`、`error.log`；历史文件位于同目录下的 `history/` 中。日志级别等可通过 `/opt/cordys/conf/cordys-crm.properties` 调整。

## 4 查看日志文件

1. 查看日志目录下的文件列表：

```sh
ls -lh /opt/cordys/logs/cordys-crm
```

2. 实时跟踪信息日志，排查进行中的问题时使用，按 `Ctrl + C` 结束：

```sh
tail -f /opt/cordys/logs/cordys-crm/info.log
```

3. 查看错误日志：

```sh
tail -f /opt/cordys/logs/cordys-crm/error.log
```

:::warning[及时留存日志]
日志按大小与时间滚动，默认最多保留约 30 天历史。排查重要问题时，请先将相关日志复制到其他目录留存。

:::


## 5 查看容器日志

应用日志会同时输出到容器标准输出，可直接使用 Docker 命令查看。

1. 查看最近的日志：

```sh
docker logs --tail 100 cordys-crm
```

2. 实时跟踪容器日志，按 `Ctrl + C` 结束：

```sh
docker logs -f cordys-crm
```

3. 按时间范围查看，例如查看最近 30 分钟的日志：

```sh
docker logs --since 30m cordys-crm
```

:::note[容器日志的留存范围]
`docker logs` 输出的内容随容器生命周期存在，容器重建（如升级、重新部署）后历史输出不再保留。需要长期留存，请导出宿主机日志目录下的日志文件。

:::
