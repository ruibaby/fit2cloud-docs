## 1 版本说明

Cordys CRM 提供社区版与企业版。社区版基于 GPL v3 开源，允许商用，并开放线索、客户、商机、合同、订单、审批流等全部核心功能。企业版在社区版之上提供品牌定制、嵌入式 BI、不限次数的 API 调用、内置 AI 工作台，以及飞致云原厂技术支持。

自 v1.8.1 起，社区版开放 API 调用，单日上限 1000 次，可接入 WorkBuddy。更大规模的对接、品牌定制与生产环境保障，使用企业版。

试用申请与商务联系见 [购买指南](https://cordys.cn/pricing.html)，咨询方式见 [商业版本](./enterprise)。

## 2 版本对比

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"16px 0 8px"}}>表 1  版本对比</div>

| 对比项 | 社区版 | 企业版 |
| --- | --- | --- |
| 授权协议 | GPL v3，开源免费 | 商业授权，按年订阅 |
| 核心功能 | 全部开放 | 全部开放 |
| Logo 和版权 | 不可替换 | 支持自定义 |
| 主题定制 | 不支持 | 支持自定义主题 |
| DataEase 嵌入式版 | 不含 | 包含 |
| API 调用限制 | 每天 1000 次 | 无限制 |
| AI 能力 | 支持接入 WorkBuddy | 支持接入 WorkBuddy，并提供内置 AI 工作台 |
| 技术支持 | 社区支持（微信群、论坛、GitHub） | 原厂企业级支持 |
| 适用场景 | 中小团队、个人试用、二次开发 | 中大型企业、生产环境部署 |
