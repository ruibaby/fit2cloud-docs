## 1 功能简介

文件管理用于在已授权资产上通过 SFTP 浏览目录，并与本地或其他已连接资产之间上传、下载和互传文件。单击菜单后会打开独立的文件管理页面（Luna）。

路径：登录后将工作区切换到 **工作台**，选择 **我的资产 > 文件管理**。

页面左右分栏：左侧为 **本地上传**，右侧为 **连接远程资产**。中间箭头用于把已选文件传到对侧。底部可在 **文件管理** 与 **传输中心** 之间切换。首次进入时，页面可能弹出功能引导，介绍工作区、路径导航、文件操作、文件列表、添加远程 SFTP 和传输中心。

:::note[与文件传输的区别]
文件管理一次连接一台或多台支持 SFTP 的资产，支持浏览、上传、下载和互传。向多台 Linux 资产按同一路径批量上传、且不需要浏览远程目录时，请使用 [文件传输](./file_transfer.mdx)。

:::


## 2 使用限制

- 仅支持具备 SFTP 协议授权的资产。不支持 SFTP 的资产无法连接，页面会提示改选。
- 左右两侧互传目前不支持整个文件夹，请先进入目录后选择文件。
- 新建或重命名时，名称不能超过 255 个字符，且不能包含反斜杠、斜杠、冒号、星号、问号、双引号、小于号、大于号和竖线。
- 文件管理依赖 Koko 组件。会话过期后需重新连接。

## 3 前提条件

- 已使用工作台账号登录 JumpServer。
- 当前用户已被授权可上传或下载文件的资产，且授权动作包含文件相关权限。授权操作请参见 [资产授权](../../../admin/console/authorization_manage/assets_authorization.mdx)。
- 文件管理依赖 Koko 组件。若打开后无法访问，请管理员检查组件状态，见 [组件设置](../../../admin/system_settings/components.mdx)。

## 4 连接远程 SFTP

1. 在右侧单击 **连接远程 SFTP**。
2. 在对话框中可搜索资产，或展开 **我的资产** 下的节点。对话框可能同时列出 **最近连接**。
3. 选择一台支持 SFTP 的资产。
4. 选择账号。可使用已授权账号，或选择 **手动输入** 并填写用户名和密码；若已在 [个人凭据](./personal_credentials.mdx) 中保存过该资产的账号，也可直接选用。
5. 单击 **连接**。连接成功后，右侧显示该资产的远程目录。

<img style={{display:"block",margin:"16px auto",maxWidth:"100%"}} src={"/jumpserver/img/jumpserver/v5_user_wb_fm_02.png"} alt="图 2  连接远程 SFTP" />

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 2  连接远程 SFTP</div>

需要同时对照多台资产时，可再单击 **添加远程 SFTP**，连接另一台资产。可用 **断开全部** 关闭当前所有远程连接。

默认进入资产所属平台配置的 SFTP 主目录。修改目录需管理员在 [平台列表](../../../admin/system_settings/platforms.mdx) 中调整对应平台。

## 5 浏览远程目录

连接成功后，远程面板工具栏可：

- 使用后退、前进、主目录切换路径。
- 单击路径空白处，直接编辑完整路径后跳转。
- 刷新当前目录，或按名称过滤当前目录中的文件。
- 选择是否显示隐藏文件。
- 在有写入权限时，新建文件夹或新建文件。

文件列表显示名称、大小、修改时间和权限。勾选文件后，底部出现已选数量和合计大小。

在文件上右击，可：

- **发送到**： 把已选文件发到对侧或其它已连接的 SFTP 目标。
- **下载**： 把文件下载到本地。下载文件夹前会再次确认。
- **重命名**： 修改当前文件或目录名称。
- **删除**： 删除前会要求确认，操作不可恢复。

也可把文件拖到对侧面板或目标标签上发送。

## 6 本地上传与双向传输

连接远程目录后：

- 将文件拖到左侧 **拖动文件到这里**，或单击 **选择文件**。文件将批量上传到右侧当前 SFTP 目录。
- 勾选一侧文件后，单击中间的箭头，传到对侧当前目录。
- 需要发到多台已连接资产时，选择 **发送到**，勾选目标机器后开始分发。遇到同名文件，可选择 **覆盖**、**跳过** 或 **保留两者**。

:::warning[先连接再上传]
未连接远程 SFTP 时，左侧提示文件将上传到右侧当前 SFTP 目录。请先完成第 4 节的连接，再选择本地文件，避免传到错误位置。

:::


## 7 传输中心

单击页面右下角 **传输中心**，可查看传输队列。没有任务时显示 **暂无文件传输任务**。

<img style={{display:"block",margin:"16px auto",maxWidth:"100%"}} src={"/jumpserver/img/jumpserver/v5_user_wb_fm_03.png"} alt="图 3  传输中心" />

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 3  传输中心</div>

队列字段包括文件、传输方向、进度、速度 / 剩余、状态、操作。可按全部、进行中、失败、已完成、已取消筛选。进行中的任务可暂停、继续或取消；失败项可重试。

关闭仍有传输任务的会话时，页面会提示关闭会中断正在进行的文件传输。

在 [Web 终端](../../web_terminal/overview.mdx) 连接资产后，展开右侧面板并切换到 **文件**，也可上传下载；过程同样可在右下角 **传输中心** 中跟踪。
