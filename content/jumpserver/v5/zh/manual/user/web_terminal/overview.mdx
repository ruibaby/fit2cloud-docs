## 1 功能简介

Web 终端（Luna）用于在浏览器中连接已授权的资产，无需安装任何插件。单击工作台中的 Web 终端入口，或单击顶部导航栏的 Web 终端图标，均可跳转到 Web 终端页面。

Web 终端界面由顶部工具栏、左侧边栏、中间会话区和底部状态栏组成：

- **顶部工具栏**：左侧为 **我的资产**、**文件管理**、**折叠侧边栏** 与 **新建连接** 按钮，右侧为 **AI 助手**、用户头像与 **右侧面板** 按钮。
- **左侧边栏**：展示当前组织下已授权给用户的资产，支持组织切换、搜索和收藏，详见 [我的资产](my_assets.mdx)。
- **中间会话区**：展示已建立的资产连接会话，支持拖拽、切换和分屏，详见 [连接资产](assets_connect.mdx)。
- **底部状态栏**：显示登录状态、会话标签数量与 **传输中心** 入口。

界面说明：

1. **我的资产** 切换到 我的资产 视图，展示当前组织中获得 **授权** 使用的资产，如果发现为空，请确认 **管理员** 是否配置好资产授权，详见 [我的资产](my_assets.mdx)。
2. **文件管理** 切换到文件管理视图，可上传本地文件或连接远程资产的 SFTP 目录进行文件传输，详见 [文件管理](../workbench/my_assets/file_explorer.mdx)。
3. **折叠侧边栏** 收起或展开左侧边栏，便于腾出更多会话区空间。
4. **新建连接** 展开 **最近连接** 列表，列出最近连接过的资产，选择其中一项可快速发起新的连接。
5. **AI 助手** 通过对话方式查询资产状态，也可以直接接管资产进行操作，需要管理员在 **系统设置** 中配置对应的智能体后使用，详见 [AI 助手](ai_assistant.mdx)。
6. **用户头像** 打开个人菜单，包含 **语言**、**主题**、**设置**、**客户端下载** 与 **退出登录** 等项，详见 [Web 终端设置](settings.mdx)。
7. **右侧面板** 展开会话面板，查看当前会话的信息与分享设置；未建立会话时显示 **暂无活动会话**。
8. **组织切换** 当前组织名称显示在侧栏顶部，单击可以切换组织，详见下节 组织切换。
9. **搜索** 输入对应资产名称快速筛选匹配资产，支持模糊匹配，详见 [我的资产](my_assets.mdx)。
10. **管理栏目** 控制侧栏中 我的资产、我的收藏、脚本库 等栏目的显示与隐藏，详见 [我的资产](my_assets.mdx)。

## 2 组织切换

单击侧栏顶部的当前组织名称，会弹出组织列表，顶部提供 **所有组织** 入口，其下列出当前用户有权限的各组织，当前所在组织以勾选状态标识。选择目标组织后，左侧边栏的资产列表随之切换为该组织下已授权的资产。

如果切换组织后资产列表为空，请确认当前用户在该组织下是否拥有资产授权。

## 3 文件管理

在 Web 终端页面单击顶部工具栏的 **文件管理** 按钮，页面切换到文件管理视图：左侧为 **本地上传** 区域，可将本地文件拖入或上传；右侧为 **连接远程资产** 区域，选择目标资产后建立 SFTP 连接，文件将批量上传到右侧当前 SFTP 目录。

会话建立后，也可在会话底部的 **传输中心** 查看传输队列与传输进度。

文件管理模块的详细说明请参考 [文件管理](../workbench/my_assets/file_explorer.mdx)。

## 4 个人菜单

单击顶部工具栏右侧的用户头像打开个人菜单，其中 **语言** 用于切换 **简体中文** 与 **English**；**主题** 用于切换 **浅色** 与 **深色** 界面；**设置** 用于配置资产连接相关参数，详见 [Web 终端设置](settings.mdx)；**客户端下载** 跳转至 JumpServer 系统周边工具下载页面，包含 JumpServer 客户端、微软 RDP 客户端、JumpServer 离线录像播放器等；**退出登录** 用于安全退出当前账号。
