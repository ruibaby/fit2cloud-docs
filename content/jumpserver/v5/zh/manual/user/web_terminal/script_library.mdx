## 1 功能简介

脚本库用于编辑和存放常用的脚本，方便在资产上执行某些操作，减少重复输入命令。脚本库入口位于 Web 终端左侧列表中，可以结合ai助手编写对应的脚本，复制到终端执行。

## 2 编写脚本

- 脚本由管理员或当前用户在 **工作台 > 作业中心 > 模版管理** 中创建
- 用户自行在web控制台左侧脚本管理处点击加号添加，添加时可以选择脚本的语言，编辑完成后ctrl+s即可保存
- AI助手编写脚本，存储到脚本库
## 3 执行脚本

1. 在 Web 终端左侧列表中选择 **脚本库**。
2. 找到具体要执行的脚本，点击复制粘贴到控制台终端，或者使用ai助手执行这个脚本

1. 选择脚本要执行的资产范围。
2. 输入或粘贴要执行的脚本，可从脚本库复制
3. 点击发送到终端，在对应资产控制台查看执行情况。

## 4 脚本的维护

脚本库中的脚本来源于 **模版管理**，可按照用途维护为 **公有** 或 **私有** 范围：公有脚本对用户可见，私有脚本仅创建者可见。

脚本模板的创建与字段说明请参考 [模板管理](../workbench/job_center/templates_management.mdx)。
