## 1 功能简介

文件管理用于查看文件传输队列。路径：登录后将控制台切换到 **工作台**，在 **Web 终端** 中打开 **传输中心**，查看已授权资产上的文件传输任务。

在 [Web 终端](./web_terminal.mdx) 中，也可单击右下角 **传输中心**，查看传输队列（文件、传输方向、进度、速度 / 剩余、状态、操作）。

:::note[文件管理入口]
当前 v5 文档以 Web 终端中的 **传输中心** 为准。若传输任务无法正常执行，请检查 Koko 组件状态，见 [组件设置](../../system_settings/components.mdx)。向多台 Linux 资产批量上传见 [文件传输](./file_transfer.mdx)。

:::


## 2 前提条件

- 已使用工作台账号登录 JumpServer。
- 当前用户已被授权可上传或下载文件的资产。
- Koko 组件运行正常。

## 3 使用说明

默认 SFTP 目录由资产所属平台决定，常见为 `/tmp`。修改目录需在 [平台列表](../../system_settings/platforms.mdx) 中调整对应平台，而不是改系统默认平台。
