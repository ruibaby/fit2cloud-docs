## 1 功能概述

- PAM（Privileged Access Management，特权访问管理）用于对企业内部的**特权账号**进行统一纳管：把散落在各资产上的本地账号收进账号库，统一执行改密、风险检测、账号发现与推送、账号备份，并完整记录账号的会话与操作行为。
- 它要解决的核心问题是：**账号分散、口令长期不变、特权操作不可追溯**。
- 在 JumpServer 中，PAM 是与「控制台」「审计台」「工作台」并列的独立模块，拥有自己的左侧导航。

进入方式：单击页面左上角的**切换器**，在下拉中选择 **PAM**。

## 2 功能构成

PAM 模块的左侧导航包含六个部分，构成"看数据 → 管账号 → 做自动化 → 控安全 → 对外集成 → 查活动"的完整闭环。

| 导航 | 包含功能 | 用途 |
|-----|---------|-----|
| 仪表盘 | — | 总览账号库规模、自动化任务分布、改密成败与账号安全风险 |
| 账号管理 | 账号、资产管理、账号模版 | 统一纳管账号与资产，按模版批量创建账号 |
| 自动化 | 账号发现、账号推送、账号备份 | 自动收集、下发、备份资产上的账号 |
| 安全设置 | 账号改密、风险检测 | 定期或手动修改账号密码，检测账号安全风险 |
| 集成 | 应用管理 | 通过 API 向外部系统提供账号密码的调用与检索服务 |
| 活动 | 账号会话、账号活动 | 查看 PAM 账号的会话记录与操作日志 |

## 3 仪表盘

- 集中总览 PAM 的运行态势，由五个区块组成：
    - **账号数据**：账号总数、特权账号、可改密、可连接、激活中五项指标，账号总数卡片内附带本周新增数量与近 7 天趋势曲线。
    - **任务汇总**：以环形图展示账号改密、账号推送、账号发现、账号备份、应用五类任务的数量分布。
    - **账号改密成功/失败**：以折线图展示所选时间段内改密任务的成功与失败次数对比。
    - **风险账号**：以条形图展示密码已过期、账号删除、密码变更、Sudo 变更、组变更、新发现、长时间未登录七类风险账号的数量。
    - **账号类型占比**：以横向条形图展示按资产平台类型（如 Linux、Windows）分类的账号数量占比。
- 详见 <a data-portal-link href="/jumpserver/manual/pam/dashboard">仪表盘</a>。

## 4 账号管理

- 用于统一管控纳管的账号与资产，支持按账号模版批量创建账号，包含三个页签：
    - **账号**：展示已纳管的所有账号，支持按最近 7 天、风险账号、账号类型等维度筛选，可通过 **创建** 手动建号或 **模版添加** 批量建号。
    - **资产管理**：展示已纳管资产及其账号信息，含上次登录时间与连接性状态。
    - **账号模版**：预定义账号的用户名、密文类型、特权账号等属性，供批量建号复用。

## 5 自动化

- **账号发现**：扫描资产并收集其操作系统上的本地账号信息，可同步绑定到对应的 JumpServer 资产，减少人工录入。
- **账号推送**：将指定账号按密码策略推送到目标资产，支持周期执行、推送后检查账号连接性。
- **账号备份**：备份 JumpServer 上所有资产账户，备份方式可选邮件发送或通过 SFTP 存入指定服务器，并支持将密钥拆分为前后两部分分别发送。

## 6 安全设置

- **账号改密**：为满足安全合规需求，定期或手动执行任务修改资产中的用户密码。改密依赖该资产的账号列表中存在**特权账号**。
- **风险检测**：检测账号长时间未登录、密码过期、弱密码、重复密码等风险，可导出风险列表并进行审核、处理或忽略。

:::warning[特权账号改密]

由于**修改特权用户的密码**属于高风险操作，JumpServer 默认不允许修改特权账号的密码。如需开启，需管理员在配置文件中添加 `CHANGE_AUTH_PLAN_SECURE_MODE_ENABLED=false`，重启堡垒机服务后生效。


:::


## 7 集成管理

- **应用管理**：为外部系统提供资产账户和密码的统一调用与检索服务（通过 API 接口访问）。
- 创建应用时可设置名称、图标、账号策略、IP 白名单、是否激活及备注；支持查看**调用记录**，并提供基于 cURL、Python、Go、Java、Node.js 的**调用示例文档**。

## 8 活动管理

- **账号会话**：查看 PAM 账号的会话记录，包含"在线会话"与"历史会话"两个页签，列表含用户、目标、账号、协议、开始日期等字段。
- **账号活动**：查看 PAM 账号相关的操作日志，列表含用户、资源、远端地址、日期、动作等字段，用于回溯账号被创建、删除、查看等操作。
