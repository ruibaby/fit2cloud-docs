## 1 功能简介

JumpServer 的运行参数保存在安装目录的 `config.txt`，控制数据库、Redis、日志、会话 Cookie、认证跳转、Syslog、录像存储等。修改前注意备份，改完重启服务生效。

## 2 配置文件位置

默认路径如下，具体参数名称、默认值与含义见 [参数说明](./env.mdx)。

```sh
/opt/jumpserver/config/config.txt
```

## 3 修改与生效

修改前先备份，再编辑：

```sh
cp /opt/jumpserver/config/config.txt /opt/jumpserver/config/config.txt.bak.$(date +%F)
vi /opt/jumpserver/config/config.txt
```

保存后重启服务：

```sh
./jmsctl.sh restart
```

:::warning[配置不会热更新]
可先执行 `./jmsctl.sh stop` 再启动，避免写到一半导致组件连接异常。启停命令见 [命令行工具](./cli_tools.mdx)。

:::
