## 1 功能简介

SQLBot 的运行参数保存在 `.env` 与 `conf/sqlbot.conf`。调整跨域、默认密码、数据库、MCP 图片地址等，一般两处一并修改后重启。

安装时由 `.env` 渲染生成 `sqlbot.conf`（如 `SQLBOT_SERVER_IMAGE_HOST` → `SERVER_IMAGE_HOST`）。安装后改参请两处保持一致。

:::


## 3 修改与生效

修改前先备份：

```sh
cp /opt/sqlbot/.env /opt/sqlbot/.env.bak.$(date +%F)
cp /opt/sqlbot/conf/sqlbot.conf /opt/sqlbot/conf/sqlbot.conf.bak.$(date +%F)
vi /opt/sqlbot/.env
vi /opt/sqlbot/conf/sqlbot.conf
```

保存后重启：

```sh
sctl restart
```

:::warning[修改后需重启]
须执行 `sctl restart` 才会生效；`sctl reload` 不能替代重启。见 [命令行工具](../installation/cli.mdx)。

:::
